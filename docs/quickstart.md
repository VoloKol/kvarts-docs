# Быстрый старт: от API-ключа до первого графика телеметрии

Эта инструкция описывает, как получить первый график телеметрии платформы «Кварц»: создать API-ключ, выполнить два запроса к Кварц API и открыть график в веб-консоли. Быстрый старт занимает около десяти минут.

## Подготовительные действия

Перед началом работы проверьте выполнение следующих условий:

- Предоставлен доступ к веб-консоли «Кварц» с ролью `editor`.
- Шлюз Кварц-T1 подключен и передает телеметрию (процедура подключения — в разделе «Подключить шлюз Кварц-T1»; статья в разработке).
- Открыт терминал с утилитой curl (Linux, macOS) или PowerShell 7 (Windows).

## Получение первого графика телеметрии

Чтобы получить график телеметрии, выполните следующие действия:
<!-- markdownlint-disable MD029 -->
1. Откройте веб-консоль и перейдите в раздел **«Ключи»**.
2. Нажмите **«Создать ключ»**, задайте имя `first-graph` и область `telemetry:read`. После сохранения ключ появится в списке со статусом **«Активен»**.

{% note warning "Значение ключа будет показано только один раз" %}

Скопируйте значение ключа сразу после создания. Повторный просмотр ключа недоступен. Система хранит ключ в зашифрованном виде. Если ключ потерян — выпустите новый ключ в том же разделе.

{% endnote %}

3. Скопируйте значение ключа и выполните запрос списка устройств. В ответе придёт JSON с полем `device_id` шлюза:

```bash
curl -H "X-Kvartz-Key: <ваш-ключ>" https://api.kvartz.example/v1/devices
```

Ожидаемый ответ — массив устройств, например:

```json
[
  {
    "device_id": "kvt-0017-a3f2",
    "name": "Шлюз цеха №2",
    "status": "online"
  }
]
```

4. Запросите последнюю телеметрию устройства — подставьте `device_id` из предыдущего шага:

```bash
curl -H "X-Kvartz-Key: <ваш-ключ>" https://api.kvartz.example/v1/devices/kvt-0017-a3f2/telemetry/latest
```

Ожидаемый ответ:

```json
{
  "device_id": "kvt-0017-a3f2",
  "metrics": { "temperature": 23.4, "humidity": 41.0, "voltage": 12.1 },
  "timestamp": "2026-11-15T09:00:00Z"
}
```

5. Откройте веб-консоль и в карточке устройства перейдите на вкладку **«Телеметрия»**. Появится график температуры за последние 24 часа.
<!-- markdownlint-enable MD029 -->
Первый график получен. Дальше вы можете настроить фильтры телеметрии (статья «Как настроить фильтры телеметрии» в разработке) или изучить описание архитектуры платформы.

## Возможные проблемы и варианты решения

### Запрос возвращает ошибку 401 Unauthorized

Проверьте заголовок `X-Kvartz-Key`: значение должно совпадать с ключом целиком, без пробелов. Ключи со статусом «Отозван» и ключи с истёкшим сроком (90 дней) не принимаются — выпустите новый ключ в разделе «Ключи».

### Список устройств приходит пустым

Пустой массив означает, что ни один шлюз не привязан к этому ключу. Проверьте область ключа (`telemetry:read`) и привязку устройства в разделе «Устройства» веб-консоли.

### Можно ли получить телеметрию без терминала?

Да: вкладка «Телеметрия» в веб-консоли показывает данные без запросов к API. Ограничение запросов через API зависит от тарифа: базовый — 100 RPS, профессиональный — 1000 RPS.
