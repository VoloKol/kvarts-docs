# Стайлгайд базы знаний для RAG-системы

> **Область действия:** база знаний (git + Markdown) и портал документации (git + Markdown + Diplodoc).
> **Для кого:** все авторы статей — техписатели, разработчики, аналитики, инженеры поддержки.
> **Как читать:** правило со словом «должен» — обязательное, проверяется в merge request; правило со словом «стоит» — рекомендуемая практика, отклонения согласуются с редактором.
