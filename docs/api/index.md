# Справочник Кварц API

Справочник описывает REST API платформы «Кварц»: авторизация по заголовку `X-Kvartz-Key`, базовый URL `https://api.kvartz.example/v1`. Лимит запросов — 100 RPS на базовом тарифе и 1000 RPS на профессиональном.

Как выполнить первый запрос — в разделе [Быстрый старт: от API-ключа до первого графика телеметрии](../quickstart.md). Правила выдачи и смены ключей — в разделе [Модель безопасности платформы «Кварц»](../security-model.md).

Методы API сгенерированы из OpenAPI-спецификации `kvartz-api.yaml` и описаны на страницах этого раздела. Коды ответов 401 и 403 описаны в каждой операции: 401 — ключ не принят, 403 — область ключа не покрывает действие.
